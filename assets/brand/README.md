# Straight Up Digital brand assets

These files are copied from the owner-supplied production brand pack and are included so the local CRM and generated audit PDFs render consistently on other machines.

- `straight-up-digital-logo-dark.png`: horizontal logo for the Obsidian CRM sidebar.
- `straight-up-digital-logo-light.png`: horizontal logo for white PDF/report pages.
- `favicon-256.png` and `symbol-full-colour.svg`: supplied icon assets.
- `fonts/`: Montserrat and Inter static weights derived from the website's self-hosted Fontsource variable fonts. The original font packages' SIL Open Font License files are included beside them.

Brand palette: Obsidian Black `#080A09`, Electric Lime `#A8FF65`, Graphite `#252B27`, Soft Ivory `#F2F4EF`. Headings use Montserrat; body text uses Inter.
